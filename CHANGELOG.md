## [0.1.1] — 2026-11-05

### Исправлено
- Озвучка XTTS-v2: модель создаётся без устаревшего `init_from_config`, без предупреждения
  в журнале и с совместимостью с будущими версиями coqui-tts.
- Поле ссылки на главном экране больше не использует устаревший параметр Flet.

## [0.1.0] — 2026-11-05

### Добавлено
- Пайплайн дубляжа: скачивание (yt-dlp + aria2c), определение языка голосованием по 5 фрагментам,
  отделение голоса от фона (Demucs), распознавание (faster-whisper) с выравниванием по словам
  (WhisperX), разделение по спикерам (pyannote, по желанию), перевод (Claude API с контекстом всего
  видео или офлайн MADLAD-400), озвучка с клонированием голоса (XTTS-v2 или F5-TTS), подгонка тайминга
  (сокращение перевода, rubberband до 1.2×, без наложений), сведение с loudnorm, сборка без
  перекодирования видео, субтитры на двух языках.
- Определение железа и пять профилей производительности, калибровка, понижение профиля при нехватке памяти.
- Интерфейс Material Design 3: главная с очередью, результат с переключением дорожек, «Моя система»,
  настройки, компоненты, «О программе», мастер первого запуска.
- Менеджер компонентов: ffmpeg, yt-dlp, Deno, aria2c и модели с проверкой SHA-256, докачкой и зеркалом.
- Установщик Inno Setup без прав администратора, портативный режим, автообновление из GitHub Releases
  с откатом.
