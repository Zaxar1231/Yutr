# Безопасность

## Поддерживаемые версии

Исправления выходят для последней стабильной версии. Программа обновляется сама.

## Как сообщить об уязвимости

Не публикуйте уязвимость в открытом issue. Используйте
[приватный отчёт](https://github.com/Zaxar1231/Yutr/security/advisories/new) на GitHub.
Мы ответим в течение недели.

## Что программа делает для безопасности

- Все скачиваемые компоненты и обновления проверяются по SHA-256 (файлы сумм издателя, хеши LFS
  Hugging Face или зафиксированные значения).
- Ключ Claude API и токен Hugging Face хранятся в диспетчере учётных данных Windows (keyring),
  а не в файлах настроек.
- Программа ставится без прав администратора и работает от имени пользователя.
- Отчёт для «Сообщить об ошибке» не содержит путей, имени пользователя и серийных номеров.
