Windows-часть проверялась в GitHub Actions на `windows-latest`. Ниже сказано честно, что проверено
на практике, что только тестами и что остаётся проверить на реальном ПК с видеокартой.

## Проверено тестами (без реального железа)

- Выбор профиля для 20+ конфигураций: RTX 4090/4070/4060 Laptop/3060/2080 Ti, GTX 1080 (без тензорных
  ядер), старый драйвер NVIDIA, RX 7900 XTX на Windows 11 (ROCm), RX 7800 XT на Windows 10 и RX 580
  (DirectML), только встроенная графика, мало ОЗУ, работа от батареи.
- Модели каждого профиля помещаются в минимальную видеопамять своего уровня.
- Понижение профиля при OOM от torch, CTranslate2, ROCm и упавшего процесса-движка.
- Разбор nvidia-smi, реестра Windows (QWORD и REG_BINARY), sysfs, вывода `ffmpeg -encoders`.
- Голосование по языку, разбивка на фразы, подгонка тайминга без наложений, срез по паузе.
- Перевод через Claude на подставном клиенте: контекст всего видео в кэшируемом системном промпте,
  бюджеты символов, повтор пропущенных id, отказ модели.
- Semver с пре-релизами, каналы stable/beta, ETag, пропуск версии, докачка с Range, zip-slip.

## Не проверено здесь — нужен ваш ПК

Перевод через Claude API: в этой среде нет ключа. Код и формат запроса проверены тестами,
но настоящий перевод и сокращение фраз нужно проверить с вашим ключом.

Видеокарта: CUDA, ROCm, NVENC/QSV/AMF, реальная нехватка видеопамяти. Чек-лист:

1. Установите `Autodub-Setup-0.1.1.exe`, пройдите мастер. Какой профиль выбран и почему — совпадает с ожиданием?
2. «Моя система»: видеокарта, драйвер, CUDA, энкодеры определены верно?
3. Переведите 5-минутный англоязычный ролик с ключом Claude. Голос похож? Рассинхрон не больше ~0,5 с? Фон сохранён?
4. Запустите параллельно игру или другую нагрузку на видеопамять — программа должна понизить профиль с уведомлением, а не упасть.
5. Переведите русский ролик — должно появиться «Видео уже на русском».
6. «О программе → Сообщить об ошибке» — откроется форма с вашей системой; приложите её к отчёту.

## Сравнение моделей озвучки

`scripts/compare_tts.py`: 20 русских фраз, один референс голоса, метрики WER (разборчивость),
похожесть спикера (WeSpeaker), RTF, плюс страница слепого прослушивания
`docs/tts-compare/index.html`. Результаты на CPU — в `docs/tts-compare/results.json`.
Естественность на слух оцените сами по слепой странице: скрипт метрик этого не заменяет.
