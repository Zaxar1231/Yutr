# Сравнение моделей озвучки

Откройте [index.html](index.html) локально (или через `python -m http.server`), чтобы послушать
вслепую: записи перемешаны, ответы спрятаны внизу страницы. Естественность на слух метрики не заменяют.

## Условия

- 6 русских фраз из `scripts/compare_tts.py`, один и тот же образец голоса для обеих моделей:
  фраза 7,4 с из интервью GET LAMP (CC BY-SA 3.0) с её точной расшифровкой.
- Машина без видеокарты (4 ядра Xeon), `device=cpu`.
- WER — синтезированная речь распознаётся обратно Whisper small; похожесть — косинус эмбеддингов
  WeSpeaker ResNet34; RTF — секунд синтеза на секунду готового звука.

## Результат

| Модель | WER ↓ | Похожесть голоса ↑ | RTF на CPU ↓ | Лицензия весов |
|---|---|---|---|---|
| XTTS-v2 | **0,017** | 0,47 | **2,5** | CPML, некоммерческая |
| F5-TTS RUSSIAN (v2) | 0,021 | **0,54** | 27 | CC-BY-NC-4.0 |

## Вывод

- Обе модели говорят по-русски разборчиво (ошибок распознавания около 2 %).
- F5-TTS заметно точнее передаёт голос, но на процессоре в 11 раз медленнее: 10 минут речи — несколько
  часов. Поэтому по умолчанию во всех профилях стоит XTTS-v2, а F5-TTS доступна в настройках и
  рекомендуется при наличии видеокарты NVIDIA.
- Важная находка при сравнении: F5-TTS обрезает образец до ~12 с, и если текст образца длиннее звука,
  модель продолжает «читать» образец вместо новой фразы. Программа даёт F5 отдельный образец
  до 10 с с точным текстом.
- Скорость на видеокарте и выбор модели по умолчанию для профилей «Высокий» и «Ультра» стоит
  перепроверить на реальном GPU: `uv run python scripts/compare_tts.py --help`.
